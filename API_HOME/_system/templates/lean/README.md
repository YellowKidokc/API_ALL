# Lean templates

Used by `55_LEAN_PAPERS`. `{{name}}` placeholders are filled by code, so every claim looks the same.

- `CLAIM_TEMPLATE.md`: one block per claim. Assumptions are deliberately left out: the claim only names them by id.
- `ASSUMPTIONS_TEMPLATE.md`: the assumptions paper for one source.

Edit the layout freely; keep the `{{...}}` names.

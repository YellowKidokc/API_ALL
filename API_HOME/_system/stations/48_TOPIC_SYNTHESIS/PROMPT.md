# 48_TOPIC_SYNTHESIS

Bridge layer, part 1: the best arguments for a topic across everything already gathered.
1. choose sources: tag score (44) or the local pass >= --min for the topic (papers, videos, EVIDENCE companions)
2. API-48.1 per source, whole text, in parallel: every argument about the topic (EXTRACT.md)
3. local: cluster the arguments across sources (cross-reference), rank by breadth then strength
4. API-48.2 per top cluster, in parallel: strongest form, lineage, objections and replies (SYNTHESIZE.md)
5. API-48.3 once: the ranked overview and gaps in the field (OVERVIEW.md)
6. local: the multi-page report; every citation is built from source metadata, never by the model

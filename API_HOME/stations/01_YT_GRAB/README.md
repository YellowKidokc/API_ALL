# 01_YT_GRAB

Download YouTube transcripts (channel, playlist or video URLs) into yt_subtitles. Then asks what to look for in this channel and whether to auto-process new videos.

- Runs: `vendor/youtube/grab/ytgrab.py` --out {yt_subtitles}
- Menu options it really accepts: limit, workers
- Script-specific options: --free-proxies, --shorts, --no-webshare
